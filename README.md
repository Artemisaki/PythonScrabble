# Scrabble Game: You vs. Computer 🧩

Play a fun game of Scrabble against the computer! 
📝 Take turns making words, score points ⭐, and see if you can outsmart the computer’s moves. It’s a great way to practice your vocabulary and have some wordy fun! 🎲

---

## Features

- Classic Scrabble gameplay
- Play against the computer opponent
- Score points by making words from letter tiles
- Easy and fun to play

---

## How to Play

1. You and the computer take turns creating words.
2. Each word scores points based on the letters used.
3. Each player is refilled with 7 seven letters everytime.
4. The game ends when there are no more tiles.
5. The player with the highest score wins!
